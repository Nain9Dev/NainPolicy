# Spec 015 — Social preview card

- Document version: 0.1
- Status: Proposed
- Date: 2026-11-03
- Owner and approval authority: Aitor Nain Mendoza Vallejo
- Governing decisions: ADR-009 (commercial layer: verifiable claims only), ADR-011 (self-hosted
  fonts, which the card renders with)
- Builds on: spec 007 (hero copy), spec 014 (fonts under `public/fonts/`)

## Problem

When `https://policy.naindev.com/` is shared on LinkedIn, Slack, WhatsApp or X, the preview
showed the generic cover of `naindev.com`. The card is the first thing a prospect sees before
deciding to click; it said nothing about policies, lost updates or the audit trail, and it was
served from another origin.

## Goal

The link preview shows NainPolicy's own promise, in the same words and identity as the hero,
rendered from the repository so it can be regenerated when the copy changes.

## Non-goals

- No per-language image; the card is Spanish, the product's approved locale, and the metadata
  declares English as the alternate locale. The page itself stays bilingual.
- No third-party image service and no runtime rendering; the PNG is committed.
- No change to the Azure `/demo/` page.

## Requirements

Notation: EARS ("When X, the system shall Y").

- `REQ-270` When the page is shared, the Open Graph and Twitter image metadata shall point at a
  card served from `https://policy.naindev.com/`, with its width, height and an alternative text
  declared.
- `REQ-271` When the card is built, it shall be a PNG of 1200 by 630 pixels, generated by a
  script in the repository (`npm run build:og`) from the hero copy, the brand tokens and the
  self-hosted fonts, so that it can be regenerated and reviewed like code.
- `REQ-272` When the page declares its locale for link previews, it shall declare `es_ES` with
  `en_GB` as the alternate.
- `REQ-273` When the card shows claims, they shall be the hero's own proofs (live on Azure SQL,
  tests against a real SQL Server, open source MIT) and nothing the page does not already claim.
